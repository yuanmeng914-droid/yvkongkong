# 明日复明日“成长日记型”页面优化设计

## 1. 目标

本次优化只重塑页面的信息层级、视觉语言与响应式布局，不改变现有业务能力。首页继续服务于“安排并完成今天的事情”，成长记录页负责“回望今天与过去”。产品整体传达轻松、温和、可以慢慢来的长期陪伴感。

## 2. 明确不变的功能

- 日期切换、任务新增、编辑、完成、删除、自动顺延和重复任务逻辑保持不变。
- 天气、心情、重要日子、成长记录、我的记忆、反馈、登录、云同步、AI 每日观察和 PWA 保持可用。
- 不修改 Supabase 数据结构、同步规则、Edge Function 或认证流程。
- 日期继续使用原有数字形式，例如“8月11日 周二”，不改成全汉字日期。

## 3. 信息架构

### 3.1 全局导航

主导航保留四个核心页面：

1. 我的明日
2. 成长记录
3. 我的记忆
4. 重要日子

“说点什么”不删除，改为右上角更明确的“写给开发者”入口，与用户账号区域相邻。点击后仍进入原反馈页面。

### 3.2 首页：行动优先

首页仍以待办事项为中心，内容顺序为：

1. 数字日期与每日文艺句子
2. 今日环境信息：天气、心情、最近的重要日子提醒
3. 任务输入区
4. 今日任务列表与完成进度
5. “剩下的，明天继续”入口

天气、心情和重要日子由三个大卡片收敛为一条较轻的“今日环境”区域，降低视觉竞争。任务列表拥有页面最高的信息权重。

### 3.3 成长记录页：回望优先

桌面端使用两栏布局：

- 左栏：月份、最近日期、心情标记和当前选择日期。
- 右栏：数字日期、当天任务结果、复盘内容、留给明天的话和 AI 每日观察。

移动端改为单栏：日期选择横向排列在正文上方，不保留狭窄侧栏。

## 4. 视觉语言

### 4.1 主题

设计方向为“成长日记”：像一本长期使用的个人记录册，而不是效率仪表盘。视觉关键词是安静、连续、轻盈、可回望。

### 4.2 色彩

- 墨绿 `#263C34`：正文与主要操作。
- 叶绿 `#5F8F7B`：选中状态、成长线索与完成反馈。
- 雾青 `#EAF2EF`：背景与上下文区域。
- 纸白 `#FBFCFB`：主要内容表面。
- 晨光橙 `#E9AD5F`：日期节点、重要提醒和少量强调。

色彩继续受真实天气背景影响，但内容表面必须保持可读性。

### 4.3 字体

- 大日期、文艺句子与成长记录标题：使用现有中文宋体回退栈，营造日记感。
- 任务、按钮、表单和说明：使用系统中文无衬线字体，保证清晰与速度。
- 时间和统计信息：使用系统字体的等宽数字特性，保持稳定对齐。

### 4.4 标志性元素

沿用并强化页面左侧的细线，使它成为贯穿每日记录的“成长线”。橙色节点表示今天，绿色节点表示已留下记录的日期。该元素只在主内容区域出现，其他装饰保持克制。

## 5. 交互与动效

- 点击“换一句”只更新句子区域，不重绘任务列表。
- 完成任务保留轻微划线与颜色过渡，不加入持续或夸张动画。
- 页面切换使用短暂淡入，尊重系统的“减少动态效果”设置。
- 所有按钮保留可见的键盘焦点状态。
- 空状态继续使用温和但明确的引导文案。

## 6. 实施边界

本次预计只调整：

- `index.html`：移动反馈入口、补充必要的布局容器和语义标签。
- `styles.css`：建立统一设计变量，重排首页、成长页和响应式样式。
- `app.js`：仅在反馈入口位置变化确实需要时做最小绑定调整；不修改任务、日期、同步、AI 等业务逻辑。

不新增第三方 UI 框架，不加载大型字体包，不改数据库和后端。

## 7. 验证标准

### 桌面端

- 数字日期、每日句子、天气、心情、任务、重要日子提醒均正常显示。
- 首页任务是最主要的视觉区域。
- 成长记录可以在日期列表与当天内容之间清晰建立对应关系。
- 四个主导航和“写给开发者”均能进入原有页面。

### 移动端

- 320px 宽度不出现横向溢出、文本重叠或按钮被裁切。
- 日期、任务输入、任务操作和成长记录按单栏正常排列。
- 导航能够访问全部页面，反馈入口可见。

### 功能回归

- 日期切换与重要日子提醒基准正确。
- 新增、完成、编辑、删除、重复和自动顺延任务正常。
- 天气、心情、登录、同步、反馈与 AI 每日观察正常。
- Service Worker 缓存版本更新，重新打开后能获取新样式。
